# 05 — One-tap Simple mode

**The idea:** a modes ladder — Fly (just the sim, beautiful, no
objectives), Wander (photo flight, landmark tours), Play (rings +
timer), Little games (ridge runner, bush pilot, daily ridge). And one
rule holding it together: **Simple is always one tap away**, turning
every game layer off and leaving just the flying.

**Why it fits iPad:** kids pick it up and put it down. A young player
should never be trapped in a mode they didn't choose; a parent
handing over the iPad should see flying, not menus. One big button.

**Where it plugs in:** game code only reads the flight controller,
never modifies it — modes are a menu over the sim, not a rebuild.
Each little game is a module that activates on opt-in; free flight
stays exactly as it is.
